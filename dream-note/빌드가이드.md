# 드림노트 — APK 빌드 가이드

맥(안드로이드 스튜디오 설치됨) 기준으로, 이 폴더를 안드로이드 앱(APK)으로 만드는 방법입니다.
명령어는 **터미널에서 이 폴더(`dream-note`) 안에서** 실행하세요.

---

## 0. 미리 준비물 확인

- **Node.js** (18 이상): 터미널에 `node -v` 입력해 버전이 나오면 OK. 없으면 https://nodejs.org 에서 LTS 설치.
- **안드로이드 스튜디오**: 이미 설치돼 있다고 하셨으니 OK.
- 안드로이드 스튜디오를 한 번 열어 **SDK / 빌드 도구**가 설치돼 있는지 확인해 주세요.

---

## 1. 의존성 설치

```bash
npm install
```

> 혹시 Capacitor 패키지 버전 경고가 나오면 `npx cap doctor` 로 점검할 수 있어요.

---

## 2. 웹앱이 잘 도는지 먼저 확인 (선택)

```bash
npm run dev
```

브라우저에서 열리는 주소로 들어가 기록·일기장·달력·통계가 잘 보이는지 확인하세요.
(이 단계에서는 음성 인식이 브라우저 기능으로 동작합니다. 실제 앱에서는 안드로이드 음성 인식으로 바뀝니다.)
확인했으면 터미널에서 `Ctrl + C` 로 종료.

---

## 3. 안드로이드 프로젝트 추가 (최초 1회만)

```bash
npm run build
npx cap add android
```

`android` 폴더가 생기면 성공입니다.

---

## 4. 권한 추가 (음성 인식용, 최초 1회)

`android/app/src/main/AndroidManifest.xml` 파일을 열어,
`<application ...>` **위쪽**에 아래 두 줄을 추가하세요.

```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />

<queries>
  <intent>
    <action android:name="android.speech.RecognitionService" />
  </intent>
</queries>
```

> 이걸 빠뜨리면 음성 버튼이 동작하지 않아요. 텍스트 입력은 권한 없이도 됩니다.

---

## 5. 빌드 → 동기화 → 안드로이드 스튜디오 열기

코드를 고칠 때마다 이 명령 하나면 됩니다.

```bash
npm run android
```

(= `웹 빌드` → `cap sync android` → `안드로이드 스튜디오 열기` 를 한 번에)

---

## 6. 안드로이드 스튜디오에서 APK 만들기

1. 프로젝트가 열리고 우측 하단 **Gradle 동기화**가 끝날 때까지 기다립니다.
2. 상단 메뉴 **Build → Build Bundle(s) / APK(s) → Build APK(s)** 클릭.
3. 빌드가 끝나면 우측 하단 알림의 **locate** 를 눌러 APK 위치로 이동.
   - 보통 경로: `android/app/build/outputs/apk/debug/app-debug.apk`
4. 이 `app-debug.apk` 파일을 본인 갤럭시로 옮겨 설치하면 끝!
   (갤럭시에서 "출처를 알 수 없는 앱 설치 허용"이 필요할 수 있어요.)

> 폰에서 바로 테스트하려면, 폰을 USB로 연결하고 안드로이드 스튜디오 상단의
> 기기 선택 후 ▶(Run) 버튼을 눌러도 됩니다.

## 자주 묻는 것

**Q. 데이터는 안전하게 저장되나요?**
네. 앱 데이터는 안드로이드 영구 저장소(Capacitor Preferences)에 저장돼서,
앱 업데이트나 캐시 삭제로는 사라지지 않아요. 가끔 **설정 → 내보내기**로 백업 파일을
드라이브/메일에 보관해두면 기기를 바꿔도 **가져오기**로 되살릴 수 있습니다.

**Q. AI 해석은요?**
키 연동 없이, 꿈 상세에서 **"AI에게 해석 맡기기"**를 누르면 해석 요청 문구가 통째로
복사됩니다. ChatGPT·Claude 등에 붙여넣으면 돼요. 앱 안에는 키가 필요 없는 오프라인
풀이도 들어 있습니다.

**Q. 음성이 안 돼요.**
4번 권한을 추가했는지 확인하세요. 또 폰에 구글 음성 서비스가 있어야 합니다.
음성이 안 되더라도 텍스트 입력은 항상 됩니다.
